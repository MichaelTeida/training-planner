# Training Planner

Training Planner is a responsive, client-side web application designed to create, manage, and track recurring workout microcycles and meso-cycles. Built with a focus on simplicity, speed, and clean typography, it allows athletes and trainers to plan workout splits, analyze training loads, and export printable sheets with zero backend dependency.

## Features

### 🟢 Meso & Microcycle Planning
Structure multi-day training routines with custom cycle lengths, customizable day names, targets, and exercise parameters (sets, reps, rest, tempo, and notes).

### 🟢 Multiple View Modes
Switch smoothly between different layout perspectives tailored to planning workflows:
- **Cycle View:** Card-based overview of the routine split with dynamic multi-column responsiveness.
- **Calendar View:** Monthly schedule view mapping cycle days onto actual calendar dates with completion checkmarks.
- **List View:** Dense, structured breakdown of exercises across the entire plan.

### 🟢 Dynamic Theme Engine
Extensive customization with 6 curated color themes:
- Obsidian Slate (Default dark)
- Emerald Mint
- Electric Amber
- Midnight Violet
- Crimson Forge
- Minimalist Light (Crisp high-contrast light theme)

### 🟢 Analytics & Volume Stats
Instant overview of cycle volume metrics, total weekly sets, estimated training time, workout-to-rest ratios, and targeted muscle group distribution.

### 🟢 Print & PDF Export Studio
Dedicated print preview mode optimized for A4/Letter formats with modular options: show/hide notes, exercise checkboxes, custom sheet titles, and compact paper modes.

### 🟢 Data Portability & Presets
- Full JSON export/import for routine backups and sharing.
- Ready-to-use built-in routine templates (Push/Pull/Legs, Upper/Lower, Full Body).
- Local storage persistence with automatic state synchronization.

### 🟢 Responsive Layout Controls
Adaptive interface with customizable column layouts (1-4 columns), mobile-optimized drawers, and fluid modals.
